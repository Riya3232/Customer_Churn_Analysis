# Customer Churn Analysis – End-to-End Data Analytics Project

## Project Overview

This project focuses on analyzing customer churn to understand why customers leave a service and identify factors that influence customer retention.

The project follows an end-to-end data analytics workflow, from data preparation and SQL analysis to interactive dashboard development and machine learning-based churn prediction.

## Business Problem

Customer churn can negatively affect business revenue and growth. The objective of this project is to analyze customer behavior, identify churn patterns, and generate insights that can help businesses improve customer retention.

## Tools and Technologies

- **SQL Server:** Data cleaning, transformation, querying and analysis.
- **Python:** Data analysis and machine learning.
- **Pandas and NumPy:** Data manipulation and preprocessing.
- **Scikit-learn:** Machine learning model development and evaluation.
- **Power BI:** Interactive dashboard and data visualization.
- **Jupyter Notebook:** Python development and analysis.

## Project Workflow

### 1. Data Preparation and SQL Analysis
- Imported customer data into SQL Server.
- Performed data cleaning and transformation.
- Analyzed customer demographics and service usage.
- Created SQL queries and analytical views.

### 2. Power BI Dashboard
- Connected the data to Power BI.
- Created interactive visualizations.
- Analyzed churn rate and customer segments.
- Presented important business KPIs.

### 3. Python and Machine Learning
- Performed exploratory data analysis.
- Prepared data for machine learning.
- Built a customer churn prediction model.
- Evaluated model performance.
- Generated predictions for new customer records.

## Key Business Objectives

- Understand customer churn patterns.
- Identify factors associated with customer attrition.
- Analyze customer demographics and service behavior.
- Predict customers who may be likely to churn.
- Support data-driven customer retention strategies.
